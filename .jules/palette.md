## 2024-06-13 - [Missing ARIA Labels on Layout Icon Buttons]
**Learning:** The application heavily relies on `<Button size="icon">` and `<Button size="icon-sm">` for core navigation actions (like closing/opening sidebars and refreshing data) without providing `aria-label` attributes. This pattern is particularly prevalent in the main application layout (`MainLayout`), which makes core navigation significantly less accessible for screen reader users. Because the interface is in Spanish, missing labels must also be provided in Spanish.
**Action:** When working on layout or navigation components in this app, proactively check for and add descriptive `aria-label` attributes in Spanish to any icon-only buttons. Watch out for duplicated component definitions (like `src/components/layout/` and `components/pos/`) and ensure accessibility fixes are applied to all instances.
